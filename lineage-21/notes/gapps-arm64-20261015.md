# ARM64 recovery and optional GApps

Publication build: `gta3xlwifi.arm64.20261015.191854`, built October 15 and
published October 16, 2026. ROM SHA-256:
`f4505aef35f10de09c629dfb6cdfffd219e5a01bf7b67c5b5bf7a6a0ad093781`.

The original MindTheGapps installer detected ARM32 recovery rather than the
ARM64 ROM. Native ARM64 TWRP fixes that architecture mismatch. Its vendor
crypto services remain ARM32 with 22 pinned source-built compatibility files
and explicit library paths. The same kernel, DTBO and FBE fixes are retained;
the compressed ramdisk fits the bootloader's 16 MiB limit.

The separate product-space constraint is fixed by moving selected apps, JNI
libraries and permission companions to system using pinned Soong patches.
All 150 previous APK names are retained. Signed product has 267,526,144 bytes
free against a 235,712,512-byte requirement including the installer's buffer.
The Google ZIP remains unchanged and selects its own minimum configuration.

A delayed Wi-Fi callback could access the setup fragment after detachment.
The Settings guard is now baked into the ROM; all three DEX files match the
physically tested app update. Source revisions, 25 clean-index-checked patches,
and the latest LineageOS 21 fetch are pinned in the adjacent lock files.

The final signed non-wiping OTA preserves all 29 mandatory original GApps
payload files through addon.d, CE storage and encryption keys. Both Mali ABIs,
98 concrete baseline HALs, Wi-Fi/app HTTPS, speaker output, both cameras and
accelerometer pass. Google Play services and Play Store run as native ARM64
processes and remain stable for 63.2 seconds with no Google crashes.

The owner confirmed Google login and a Play Store app download on the initial
GApps build 140343. The unchanged ARM64 TWRP passed manual PIN and automatic
PIN-free CE read/write and normal Android return on that build. Its entire
partition is preserved by the final OTA. No data format was performed for the OTA.

Vendor readback differs only in 18 bytes of ext4 mount bookkeeping. All other
343,932,928 partition bytes match the reviewed image. Read-only e2fsck passes;
a negative test confirms that the readback checker rejects a changed data byte.
