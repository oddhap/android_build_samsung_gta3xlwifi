# Direct private-property ownership inventory

This read-only inventory of the actual staged vendor context labels and linked
Android17 policy identifies 118 exclusive vendor-private property types. Of these,
98 have no direct owner membership in the parsed positive lists. Seventy-seven
types have no label reference in this vendor_property_contexts file; 41 have only
vendor namespace prefixes. This is not a complete transitive attribute closure,
effective writer analysis, global labeling audit or property runtime test.

The report records exact context names, direct writer grants, known direct core
or broad writer symbols and all source hashes. Missing or mixed-prefix contexts
do not trigger automatic classification. In particular, properties with observed
core writers are not silently assigned public scope. A repeated inventory bound
to the narrowed legacy-access input is retained with that experiment and is the
actual input to the subsequent explicit 32-type owner proposal.

This audit changes no policy, context, image or source. It is not security approval.
