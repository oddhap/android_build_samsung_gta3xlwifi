# Builtin interface accounting match

A tenth isolated builtin match exposes the real kernel interface-counter producer
as `-m gta3xlwifi_iface_stats --direction ingress|egress`. Direction is mandatory;
other spellings and inversion are rejected. The eight-byte payload is initialized
to zero and parse failures leave it unchanged. Save output is canonical.

Twenty-five host callback tests pass against the hash-bound prior xtables API
fixture. The actual Android17 filter/registry generators reproduce the original
registry, build all ten private extensions and the complete libext archive, and
link the full ARM64 iptables binary. All 80 registrations remain present; final
machine-code checks verify all ten private match registrations. Original dynamic
library dependencies and all original production objects are preserved. Android
before/after source audits pass for 1243 projects and 17 exact patches.

The patch and every unchanged prerequisite are hash-locked; independent patch
replay passes. No rules are installed or executed by this build. Mandatory option
engine behavior and runtime kernel accounting remain unvalidated. Source startup
must install the producer rules together with matching egress-policy DROP UNDO;
this plugin alone is not accounting or network readiness. No Android source or
selected kernel/vendor/DTBO is changed and no binary is published.
