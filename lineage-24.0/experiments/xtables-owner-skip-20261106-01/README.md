# Ordinary packet exemption xtables registration

Adds one no-option private builtin gta3xlwifi_owner_skip match alongside the four
unchanged prior private extensions. Payload is initialized to four zero bytes;
its UAPI is compared with the full isolated kernel tree before native compilation.
The actual Android registry generator, full archive, final ARM64 iptables link,
all old registrations plus all five private final machine-code registration
paths are checked. No CLI parser, kernel rules or packets are executed.

This is an inactive source proposal. An ordinary-owner skip must never be used
to bypass metered, local-network, loopback or other independent packet policy.
A complete authoritative dispatcher/lifecycle/framework provider remains required.
