# Private non-loopback xtables registration

Adds one no-option zero-payload builtin match, retaining the exact five earlier
private extensions and all original extensions. UAPI header layout is unchanged;
the added macro declares the new match name. Header identity with the full kernel
is checked. Native validation rebuilds real init registry, complete archive and
whole ARM64 iptables, checking all70 old plus six private registrations and final
machine-code registry paths. No rules, packets or complete network backend run.
The kernel routing limitation must be resolved before any activation.
