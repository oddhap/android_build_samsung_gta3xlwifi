# Held interface accounting startup in the shared policy owner

A new AccountingRoots component accepts only the exact explicitly built source
factory program. Product Fwmark, frozen INetd18 CLAT_MARK and rule defaults are
bound by executing the actual factory. Actual Android17 MARK revision2 save and
policy print_flags bodies establish the four canonical spellings used to verify
ordered readback. This is not a general interpreter for caller or live-rule text.

Before its first write, prepare reads both families/all three tables and requires
all eight existing owned chains to be EMPTY or exact known ordered prefixes.
Old BPF, foreign or differently ordered owned rules are rejected, never flushed
or replaced. Missing prefix rows are appended from compiled source only. After
all writes, exact owned readback and all captured foreign declarations, builtin
policies and rules must match. Failure closes the same real held lease; there is
no automatic rollback or foreign-text replay. Partial startup can be explicitly
retried against known prefixes. Current raw/mangle producers can be reverified
without rejecting legitimate later filter quota/bridge changes.

SocketPolicyProjection::startWithAccounting(program, mode) checks all twelve real
primitives, prepares/verifies the six global guards, bootstraps the producers,
then prepares the private socket/metered roots. It remains held and unpublished.
The sole lease/mutex is shared with the four authoritative policy values. Every
accounting-enabled replacement verifies raw/mangle producers both before writes
and after final firewall/parent work. All checks finish BEFORE LNA SET and UID
SET last; RELEASE precedes one atomic four-value commit. Error withdraws all
values and accounting mode. There is no exposed FD, second owner or Ready flag.

The controller/startup caller must invoke this AFTER the last generic bandwidth
reset and route later data-saver policy to this owner. It must prevent late
flushes of active bridges/producers. This does not wire actual Controllers,
Binder/Java, UID/tag/app/bank/counter-set statistics or metrics delivery. The
original generic policy-only start remains explicitly separate and cannot be
interpreted as whole-network readiness.

- Accounting-enabled owner host03: 1245 cases; every 73 startup and 114 update
  I/O points before/after failure, all twelve primitive absences, stale startup,

  program writes is caught before either image SET. Root NoInternet remains
  honestly fail-closed, with no permission bypass/auto-clear. Instrumentation

- Native01: fourteen actual sources (including the complete BandwidthController)

  real ARM32/ARM64 layouts, seven exact private UAPIs, 1243-project/17-patch audits
  and no unresolved private namespace symbols all pass. Factory compilation uses
  its own actual per-file command. Both host reports bind the same current source.
- All four new source deltas/dependency sets independently replay with exact
  before/after/patch hashes.

Syscalls, table effects and payloads in host tests are fixtures. No real rules
are installed, Android source/kernel/policy selected, binary/key published or
device flashed. A full test-ROM candidate still requires UID accounting, actual
service/startup routing, selected strict policy/image integration, encryption/
rollback checks, installer validation and final non-A/B OTA build.
